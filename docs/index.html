Blocks

Tap to add a block to the canvas.

Wiring Drag from the round port on the right of a card towards the next card — the wire magnetises to the nearest port, and dropping it anywhere on a card uses that card's first free input. On touch: tap the output port, then tap the destination card or port. Press and hold a port (or right-click it) to add a new block that is already wired to it. To remove a wire, tap it so it lights up, then tap Delete wire — no keyboard needed on a phone.

Keeping it readable Arrange glides the blocks into flow order and drops every input right next to the block it is wired into (not in a far-left column), Compact shrinks every card to a mini overview (or the − button shrinks one card), and the target button on a card opens just that block with everything it is built from.
Start here Add a Value input from the Blocks palette, wire it into a Compute block, then mark that Compute block as an outcome to see the result.
